# Синергия

Синергия - это мера сплоченности [[bpm/Термины/Кабинет|Правительства]]. Чем выше синергия, тем эффективнее [[bpm/Термины/Кабинет|Кабинет]] будет в реализации политики.

Синергия рассчитывается на основе идеологической близости каждого из ваших [[bpm/Термины/Министр|министров]], наиболее влиятельным из которых является глава правительства. [[bpm/Термины/Институциональная группа интересов|институциональные влиятельные группы]] реже конфликтуют друг с другом, тогда как [[bpm/Термины/Идеологическая группа интересов|идеологические влиятельные группы]] должны иметь схожие идеологии, чтобы избежать столкновений. Определенные политические системы могут испытывать больше трудностей в достижении высокофункционального [[bpm/Термины/Кабинет|Правительства]] по сравнению с другими.
