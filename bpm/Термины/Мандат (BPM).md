# Мандат (BPM)

Получая от [[vanilla/Термины/В правительстве|правительственного]] [[vanilla/Термины/Уровень влияния|Уровень влияния]] и взвешивая по принципам исполнительной власти законов, Мандат распределяется между вашими [[vanilla/Термины/Заинтересованная группа|группами интересов]] и может быть потрачен на [[bpm/Термины/Назначение министра|назначение министров]]. Определенные [[vanilla/Термины/Заинтересованная группа|группы интересов]] больше подходят для определенных [[vanilla/Термины/Институт|министерств]] и требуют меньше Мандата для назначения.
