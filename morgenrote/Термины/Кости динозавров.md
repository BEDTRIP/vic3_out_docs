# Кости динозавров

[[morgenrote/Термины/Палеонтолог|Палеонтолог]] может находить кости динозавров в великих [[morgenrote/Термины/Формация|формациях]].
**Опытный палеонтолог** также может попытаться реконструировать **кость динозавра** из 20 фрагментов [[morgenrote/Термины/Окаменелость|окаменелостей]]. **Кость динозавра** может быть реконструирована только в том случае, если для ориентира доступна хотя бы одна кость динозавра.
Для выполнения любого из этих действий палеонтолог не должен быть истощён или занят. Успех во многом зависит от его палеонтологического [[morgenrote/Термины/Опыт (Morgenröte)|опыта]].
**Кости динозавров** используются для реконструкции [[morgenrote/Термины/Скелет динозавра|скелетов динозавров]].
