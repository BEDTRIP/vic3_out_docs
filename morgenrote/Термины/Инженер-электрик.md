# Инженер-электрик

**Инженер-электрик** специализируется на улучшении вашей страны с помощью электрических инноваций.
Такой инженер может начинать **инженерные проекты** для исследования геомагнитного поля Земли, для строительства телеграфных или радиосетей или для исследования электрических [[vanilla/Термины/Технология|технологий]].
