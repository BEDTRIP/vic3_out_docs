# Лекарственные растения

Лекарственные растения обладают целебными свойствами, которые можно использовать для создания фармацевтических препаратов и других полезных химических веществ.
Вы можете собирать лекарственные растения, отправив [[morgenrote/Термины/Натуралист|натуралиста]] в [[morgenrote/Термины/Ботаническая экспедиция|ботаническую экспедицию]]. Когда будет собрано достаточно растений, [[morgenrote/Термины/Химик|химик]] сможет приступить к выделению химического вещества. После этого [[morgenrote/Термины/Биолог|биолог]] сможет начать производство фармацевтического препарата.
