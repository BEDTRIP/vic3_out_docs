# Инженер-строитель

**Инженеры-строители** специализируются на улучшении инфраструктуры страны.
Они могут начинать **инженерные проекты** для добавления [[vanilla/Термины/Модификатор|модификаторов]] к областям, которые повышают [[vanilla/Термины/Инфраструктура|инфраструктуру]], для улучшения ваших **строительных секторов** или для исследования [[vanilla/Термины/Технология|технологий]].
