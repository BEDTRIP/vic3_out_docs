# Авиаконструктор

**Авиаконструктор** специализируется на разработке средств для полётов и улучшении самолётов и цеппелинов.
Такой инженер может начинать **инженерные проекты** для добавления [[vanilla/Термины/Модификатор|модификаторов]] к вашим аэропортам, которые улучшают [[vanilla/Термины/Товарооборот|производительность]], [[vanilla/Термины/Производство|производство товаров]] и [[vanilla/Термины/Потребление товара|затраты сырья]], для разблокировки передовых самолётов в качестве [[vanilla/Термины/Вариант мобилизации|вариантов мобилизации]] или для исследования авиационных [[vanilla/Термины/Технология|технологий]].
