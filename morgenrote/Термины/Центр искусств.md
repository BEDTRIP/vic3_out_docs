# Центр искусств

**Центр искусств** - это центр [[morgenrote/Термины/Художественный стиль|художественного стиля]], который создаётся в [[vanilla/Термины/Регион|регионе]] после изобретения **художественного стиля**. На каждый **художественный стиль** приходится только один **центр искусств**.
**Центры искусств** особенно важны для [[morgenrote/Термины/Художник|художников]], которые могут совершать [[morgenrote/Термины/Образовательное путешествие|образовательные путешествия]] для изучения **художественного стиля**. Кроме того, в некоторых **центрах искусств** происходят уникальные события; например, там можно получать [[morgenrote/Термины/Художественный приз|художественные призы]].
