# Сооружения по чертежам

Сооружения по чертежам - это сооружения, для которых требуется чертёж, исследованный [[morgenrote/Термины/Архитектор|архитекторами]]. Эти сооружения могут быть построены только один раз в державе. Существует 15 различных сооружений:

**Памятник**
- Статуя
- Фонтан
- Триумфальная арка

**Общественная площадь**
- Общественный парк
- Луна-парк
- Плац

**Служебные сооружения**
- Государственная богадельня
- Государственная школа
- Государственная тюрьма

**Учреждения здравоохранения**
- Канализационная система
- Университетская больница
- Департамент здравоохранения

**Национальные академии**
- Национальная академия наук
- Национальная академия искусств
- Национальная академия спорта
