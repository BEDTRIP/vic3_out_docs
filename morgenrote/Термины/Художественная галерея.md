# Художественная галерея

**Художественная галерея** - это особое сооружение в столице державы, доступное начиная с **реализма**. Его можно построить, только если у державы есть [[morgenrote/Термины/Художник|Художник]] со специализацией. **Художники** со специализацией открывают коллекцию своего [[morgenrote/Термины/Художественный стиль|художественного стиля]] - то есть художник со специализацией в романтическом стиле открывает коллекцию романтизма. Чтобы улучшить коллекцию до превосходной, требуется шедевр такого рода, который должен быть либо написан художником, либо приобретён за границей.
