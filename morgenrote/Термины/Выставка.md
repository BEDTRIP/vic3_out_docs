# Выставка

Ваш [[morgenrote/Термины/Археологический музей|Археологический музей]] будет автоматически организовывать выставки (в виде [[vanilla/Термины/Производственный метод|метода производства]] для каждого региона), если у вас будет достаточно [[morgenrote/Термины/Артефакт|малых артефактов]] одного вида. Для обычных артефактов первая выставка будет создана при наличии 10 или более артефактов. Затем можно проводить выставки более высокого уровня: среднюю — при 25, большую — при 50 и превосходную — при 100 малых артефактах. Для превосходной выставки дополнительно требуется один [[morgenrote/Термины/Крупный артефакт|крупный артефакт]].

Местные артефакты имеют менее разнообразный набор выставок, так как они ограничены обычной и большой выставкой. Для обычной выставки требуется 25 местных артефактов, а для большой - 50.
