# vic3_out_docs — документы внешних источников

Граф документов каждого источника, на котором стоит проект vic3: ваниль Victoria 3 и чужие моды. Сами источники —
снимок в `vic3_mods_out/` (локальный git, руками не править); здесь — только наш текст о них
([[Внешний источник|методика]], решения узла [[Д.ДОК.5 — документация внешних источников|Д.ДОК.5]],
[[Д.ДОК.12 — репо документации out|Д.ДОК.12]]).

- **Снимок — 1.13**, заморожен до конца документации ([[Д.ДОК.13 — версия источников|Д.ДОК.13]]): `verified` у заметок
  — коммит снимка `vic3_mods_out`.
- **Папка на источник**: `vanilla/`, дальше — `ef/`, моды пачки, аддоны ([[Д.ДОК.17 — порядок источников|Д.ДОК.17]]).
- **Граф источника** описывает только сам источник — «как сделано»; как им пользуется форк или другой мод — в их
  заметках с `uses` / `replaces` ([[Д.ДОК.15 — кто описывает использование ваниль|Д.ДОК.15]]). Слои — термины, объекты,
  области реализации, механики, потоки ([[Д.ДОК.16 — слои графа источника|Д.ДОК.16]]).
