# Миграционная привлекательность

Миграционная привлекательность показывает способность [[Область|области]] привлекать мигрантов. Она главным образом зависит от [[Уровень жизни|уровня жизни]] [[Группа населения|населения]] области, но на неё могут влиять и иные факторы. [[Безработные|Безработица]] в области снизит её миграционную привлекательность. Значение сравнивается с показателем для других областей, между которыми может происходить миграция, чтобы определить преимущественное направление миграционного потока.

Миграционная привлекательность также является главным фактором, определяющим [[Привлекательность для массовой миграции|привлекательность]] страны для массовой миграции.
