# Инвестиционный пул

[[Реинвестиции]] от [[Группа населения|населения]] имеющими в [[Частная собственность|частной собственности]] [[Сооружение|сооружения]], попадают в инвестиционный пул и используются для [[Частное строительство|частного строительства]] и покупки [[Уровень сооружения|уровней сооружений]], выбранных для [[Приватизировать|приватизации]].

Обычно инвестиционный пул используют аристократы и капиталисты, чему способствуют усадьбы и финансовые районы соответственно. Экономическая система вашей страны определяет, может ли [[Рабочая сила|рабочая сила]] использовать пул для расширения собственного сооружения.

Экономическая система [[Страна|страны]] ограничивает перечень сооружений, которые можно строить с помощью инвестиционного пула.

По мере возведения сооружений средства на строительство выделяются из инвестиционного пула и поступают в [[Казна|казну]] в виде [[Трансфер инвестиционного пула|денег из инвестиционного фонда]].
