# Массовая миграция

Массовой миграцией называется перемещение большого количества [[Группа населения|групп населения]] определённой [[Культура|культуры]] между двумя [[Страна|странами]]. [[Цель миграции|Цели массовой миграции]] могут появляться при наличии [[Торговля|торговых]] отношений между двумя [[Рынок|рынками]], если [[Культурная революция|культурная революция]] в исходной стране достигла как минимум значения `NPops.MASS_MIGRATION_ORIGIN_MIN_TURMOIL`. Чем выше [[Привлекательность для массовой миграции|привлекательность для массовой миграции]], тем больше вероятность, что одна из областей страны станет её целью.
