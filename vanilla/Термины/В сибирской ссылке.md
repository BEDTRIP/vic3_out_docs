# В сибирской ссылке

[[Персонаж|Персонажа]] можно отправить в ссылку с помощью действия «**Ссылка в Сибирь**». Персонаж становится [[Агитатор|агитатором]] и изгоняется в Сибирь.

**Изгнанные в Сибирь персонажи видны только [[Страна|странам]], для которых выполняются следующие условия:**
- Русские — [[Основные культуры|основная культура]]
- Владеют [[Область|областью]] в регионе Сибирь
- **Не** [[Принятие законов|принят]] никакой вариант закона «Защита свободы слова»
- **Не** [[Принятие законов|принят]] никакой вариант закона «Гарантия свобод»

Сосланный персонаж вернётся из ссылки только по истечении положенного срока.
