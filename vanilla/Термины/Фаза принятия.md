# Фаза принятия

Чтобы [[Принятие законов|принять]] [[Закон|закон]], необходимо провести его через каждую из `NPolitics.LAW_ENACTMENT_MAX_PHASES` фаз - `GetPlayer.GetCustom('enactment_phase_0')|v`, `GetPlayer.GetCustom('enactment_phase_1')|v` и `GetPlayer.GetCustom('enactment_phase_2')|v` -с максимальным [[Успех принятия|успехом]]. Если в процессе принятие закона будет [[Заминка при принятии|затягиваться]], оно может закончиться неудачей.
