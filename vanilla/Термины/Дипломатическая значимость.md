# Дипломатическая значимость

Чтобы [[Страна|страна]] могла использовать определённые взаимодействия, например подписание [[Договор|договоров]], она должна быть дипломатически значимой. Страна считается значимой для другой при выполнении одного из следующих условий:
- У них есть общая граница
- У них есть общая граница с одним [[Морской узел|морским узлом]] между ними
- Одна страна граничит с [[Субъект|субъектом]] другой
- Субъект одной страны граничит с субъектом другой
- Между странами подписан договор
- Обе страны являются [[Великая держава|великими державами]]
- Одна из стран объявила другую [[Соперничество|соперником]]
- Одна страна осуществляет [[Пиратство|пиратство]] в отношении другой
- У стран есть пересекающиеся [[Интерес|интересы]]
