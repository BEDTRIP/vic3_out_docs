# Контроль над проливами

Контроль над проливом принадлежит [[Страна|странам]], владеющим двумя [[Область|областями]], расположенными по обоим берегам [[Пролив|пролива]]. Каждая страна, владеющая такой областью, считается контролёром пролива и может [[Доступ к проливам|ограничивать]] судоходство через пролив. Исключением является **Гибралтарский пролив**: для того чтобы его **закрыть**, необходимо владеть областями по обеим сторонам пролива.

Если державы, владеющие землями по обеим сторонам пролива, установили разные ограничения доступа, действует более строгое из двух ограничений.
