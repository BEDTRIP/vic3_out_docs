# Основная группа принципов

Основная группа принципов зависит от выбранной [[Главенствующая идея|главенствующей идеи]] [[Блок государств|блока]]. Для поддержки стабильной [[Сплочённость|сплочённости]] блоку необходимо иметь хотя бы один [[Принцип|принцип]] из основной группы. [[Мандат|Утверждение]] принципов более высокого уровня (II и III) из основной группы дополнительно усиливает сплочённость.
