# Пахотные земли

Количество земли в [[Область|области]], которую можно использовать для выращивания урожая и выпаса скота. В отличие от [[Сооружение|сооружений]], требующих для строительства определённый [[Ресурсный потенциал|ресурсный потенциал]], пахотные земли приходится делить между всеми типами использующих их сооружений.

Неиспользуемые пахотные земли могут использоваться [[Сооружение натурального хозяйства|сооружениями натурального хозяйства]], что позволяет [[Группа населения|населению]] получать необходимый минимум для жизни, не имея полноценной работы.
