# Военный лидер

Одна из [[Страна|стран]] с каждой из сторон [[Война|войны]] считается военным лидером своей стороны, и обычно, хоть и не всегда, эти же стороны являются [[Инициатор|инициатором]] и [[Цель|целью]] [[Дипломатическая игра|дипломатической игры]], которая привела к войне. Только эти две страны могут предлагать [[Мирный договор|мирные договоры]], хотя любой договор должен быть ратифицирован всеми договороспособными участниками войны.
